## Bonus packs (desert, forest, mountain, tundra)

`packs/` holds cmartins' bonus Desert, Forest, Mountain and Tundra hex packs as supplied (pointy-top tiles with the ground painted in), licensed **CC BY** ("Art by C. Martins", see `packs/tundra/tundra_00_by.png`). Supplied by Heph on 2026-11-04.
`features/` holds the same art with the painted ground keyed out (`tools/tiles_key.py`), so a feature can sit on our own hex colours like the icons above. Credit: **Art by C. Martins (https://cmartins.itch.io), CC BY.**
