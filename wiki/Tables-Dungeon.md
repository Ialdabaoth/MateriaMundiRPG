## B. Random Tables:

## Dungeon Generation

There are thousands of beautifully illustrated dungeon maps to download on the internet, many of which are completely free to use. You can also sit down and create your own, if you are so inclined.

Whenever you need to generate a dungeon procedurally, you can do so via the following tables.

### The Entrance

Before  the party even enters the dungeon, they must find the entrance from the wilderness. Some dungeon entrances are wellhidden, while others are conspicuous. The architecture of the entrance should usually match the architecture of the dungeon itself, unless the dungeon has been renovated by more recent inhabitants. If you haven’t decided, you can roll a d6 and choose randomly, ignoring or re-rolling any result that doesn’t fit the theme of the local environment:

| D6 | Dungeon Type |
|---|---|
| 1 | Imperial Ruins |
| 2 | Atlantean / Lemurian Ruins |
| 3 | Draconic Temple |
| 4 | Qlippothic Incursion |
| 5 | Fey Demesne |
| 6 | Orcish War Camp |

### Rooms and Corridors

Rooms and corridors can also be determined by a die roll, if necessary. A corridor will typically extend 2d6+3 paces forward before another decision point needs to be made. You can roll a d20 + d6 at each decision point:

| D20 | Corridor Direction |
|---|---|
| 1-6 | 90 degrees left |
| 7-12 | 90 degrees right |
| 13-17 | Open into larger chamber (d20) |
| 18-20 | Continue straight for 1d6 paces further |

| D6 | Corridor Doorway |
|---|---|
| 1-2 | No door |
| 3 | Open door |
| 4-5 | Closed door |
| 6 | Locked door |
| D20 | Chamber Shape and Size |
| 1-4 | Square (2d6+3 paces per side) |
| 5-6 | Rectangle (2d6+3 x 2d6+3 paces) |
| 7-8 | Rectangle (d6+2 x d6+2 paces) |
| 9-10 | Circle (2d6+3 paces diameter) |
| 11-12 | Circle (d6+2 paces diameter) |
| 13-14 | Oval (2d6+3 x 2d6+3 paces) |
| 15-16 | Oval (d6+2 x d6+2 paces) |
| 17-20 | Cave or unusual shaped room |

If the dungeon path would loop back on itself, you can instead use the doorway d6 to decide whether to end at a secret door (1), or stairs going down to the next level (2-6).

### Hidden Secrets

You can also create tables for whether each area of a randomly generated dungeon contains secret traps, hazards, or hidden treasure. Trap and hazard rolls can vary wildly, based on how dangerous you want the dungeon to be; the following d20 charts are simply examples of possibilities.

D20 Room Secrets

1 Door is trapped, requiring a Dexterity save to avoid

some kind of damaging attack

2 Door is trapped, requiring a Constitution save to

avoid a poisonous gas

3 Door is trapped, requiring a Strength save to avoid a

pitfall.

4-5 There is a secret cache hidden in the room, which

hides some form of treasure; roll 1d6 to determine

if the cache is trapped (on a 1-3, use this table for

the trap type; on a 4-6, there is no trap).

6 There is a treasure cache prominently displayed

somewhere in the room; roll 1d6 to determine if the

cache is trapped (on a 1-3, use this table for the

trap type; on a 4-6, there is no trap).

7 There is a secret floor panel somewhere in the room

that activates a room-wide trap; roll 1d6÷2 on this

table to determine the nature of the trap (on a ‘1’,

reroll two dice and apply both trap types).

8 There is a secret door somewhere in the room that

leads to a nearby area of the dungeon; roll 1d6 to

determine if the door is trapped (on a 1-3, use this

table for the trap type; on a 4-6, there is no trap).

9-18 The room contains no secrets

19 Roll a d6 and consult this chart twice
