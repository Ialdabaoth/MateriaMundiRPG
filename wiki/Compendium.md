# Materia Mundi: Compendium rules

The full rules of *Materia Mundi: Compendium* (first edition, June 2026): the Player's Guide, Panoply, Magic, Bestiary, Referee's Guide and Appendices. The History chapter, which describes the default setting, isn't included here. Each page ends with the book pages it comes from.

The Compendium builds on the [E9 System Reference Handbook](E9) and changes some of its rules, so the two rulesets have separate pages.
